
## Quick-Use

**Commands**:
- `tmux` - starts tmux session. While in session:
    - The default key to input `tmux` commands prefix is `[CTRL + b]`.
    - `[CTRL + b > c` -> opens a new window
    - `[CTRL + b > WINNUM]` -> shifts to window number
    - `[CTRL + b > SHIFT + % ]` -> split window vert
    - `[CTRL + b > SHIFT + "]` -> split window horz
